What is Git?

Git is a tool used to manage and monitor changes in project files. It helps developers maintain different versions of their code and restore previous versions if needed. Git is widely used in software development.

What is GitHub?

GitHub is a cloud-based service where Git repositories can be stored. It enables developers to work together on projects from different locations. GitHub makes sharing and managing code easier.

What is a Branch?

A branch is a copy of the project’s code that allows independent development. Developers use branches to test changes or build features safely. The branch can be merged back after the work is completed.

What is a Commit?

A commit records the changes made to files in a repository. It acts like a checkpoint that saves the current state of the project. Every commit has a unique ID and a descriptive message.

What is a Pull Request?

A pull request is a feature on GitHub used to propose changes from one branch to another. It gives others an opportunity to review and discuss the changes before merging. This helps maintain code quality and teamwork.
